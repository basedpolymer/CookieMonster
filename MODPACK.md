# The modpack I run alongside this fork

These are the other mods I have installed on Steam Cookie Clicker. Nothing here is rehosted. Every link goes to the original author's Steam Workshop page, and that's where you install them from: open the page, hit Subscribe, and Steam downloads the mod for you. Workshop mods then show up under Options → Mods → Manage mods.

The one exception is Cookie Monster itself, which is a local mod (see [`steam/README.md`](steam/README.md)).

## Cookie Monster (this fork)

The repo you're reading: <https://github.com/basedpolymer/CookieMonster>. Installed manually into `mods\local\`, not through the Workshop.
